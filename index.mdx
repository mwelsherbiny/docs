The Felops API is a REST API for managing your workspace's integrations, the actions your agents can run, and the history of executed actions. This page covers the base URL, authentication, and the response and error formats every endpoint shares.

## Base URL

```text
https://felops-backend.onrender.com/api/v1
```

## Authentication

Every endpoint except `GET /health` requires a bearer token (JWT) in the `Authorization` header.

```bash
curl https://felops-backend.onrender.com/api/v1/integrations \
  -H "Authorization: Bearer <your-token>"
```

## Response format

Successful responses wrap the payload in a `data` field. List endpoints can include a `meta` object with pagination details.

```json
{
  "data": [],
  "meta": { "page": 1, "limit": 20, "total": 0, "totalPages": 0 }
}
```

Paginated endpoints accept `page` (default `1`) and `limit` (default `20`, maximum `100`) query parameters.

## Errors

Errors return an `error` object with a stable `code` and optional `details` for field-level problems.

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "details": [
      { "field": "password", "code": "TOO_SHORT", "params": { "minLength": 8 } }
    ]
  }
}
```
